<b>GCWUS Department of Computer Science Website<b>

A modern, responsive website for the Department of Computer Science at Government College Women University Sialkot (GCWUS). The website provides an overview of academic programs, faculty members, research areas, computing laboratories, departmental news, and contact information.

📌 Project Overview

The purpose of this project is to create a professional and user-friendly online platform that presents departmental information in an organized and visually appealing way. It features a clean interface, responsive layouts, interactive elements, and easy navigation for students, prospective applicants, faculty, and visitors.

✨ Features
Responsive Navigation: Desktop navigation bar and collapsible mobile menu.
Hero Section: Introduction to the department with prominent call-to-action buttons.
About the Department: Vision, mission, and academic excellence sections.
Academic Programs: Information about BS Computer Science, BS Information Technology, and MS Computer Science.
Program Details Modals: Interactive pop-up windows displaying program duration, eligibility criteria, overview, and core courses.
Faculty Directory: Faculty profiles with names, designations, qualifications, and specializations.
Faculty Search and Filtering: Search faculty by name and filter them by category.
Research Areas: Highlights artificial intelligence, data analytics, cybersecurity, and cloud systems.
Computing Laboratories: Information about software engineering, AI and data science, and networking labs.
News and Events: Displays departmental announcements, workshops, competitions, and admission notices.
Contact Section: Department contact details and an inquiry form.
Interactive Notifications: Modal dialogs for program information and form-submission feedback.
Modern UI Design: Tailwind CSS styling, Font Awesome icons, custom colors, hover effects, and animations.
Smooth Navigation: Section-based navigation with smooth scrolling.
🛠️ Technologies Used
HTML5 — Website structure and content.
Tailwind CSS — Responsive layouts and utility-based styling.
Custom CSS — Glassmorphism effects, image overlays, and animations.
JavaScript — Mobile menu, faculty filtering, program modals, and form interactions.
Font Awesome — Icons and visual elements.
Google Fonts (Inter) — Typography.
Unsplash — External images used for visual presentation.

🚀 Getting Started
Prerequisites

You only need:

A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
A code editor such as Visual Studio Code (optional).

An internet connection is recommended because Tailwind CSS, Font Awesome, Google Fonts, and the website images are loaded from external sources.

Installation
Open index.html in your browser.
Alternatively, open the project folder in Visual Studio Code and run the HTML file using the Live Server extension.
💻 How to Use
Open the website in your browser.
Navigate through the sections using the navigation bar.
Explore the available academic programs and click View Program Details to view additional information.
Search for faculty members or filter them by category.
Explore the research areas and computing laboratories.
Browse the news and events section.
Use the contact form to demonstrate the inquiry interface.
📱 Responsive Design

The website uses Tailwind CSS responsive utility classes to adapt its layout to different screen sizes, including:

Desktop computers
Laptops
Tablets
Mobile phones

The navigation menu changes to a collapsible mobile menu on smaller screens.

⚙️ Current Limitations
The contact form currently displays a success notification without sending data to a server or email address.
Faculty search and filtering operate on the faculty entries included in the HTML.
Program details are stored in a JavaScript object rather than a database.
News, events, admission details, and faculty information are presented as static content.
External fonts, icons, stylesheets, and images require internet access.
The website does not currently include a backend, database, authentication, or an administrative dashboard.

Note: The displayed faculty details, admission criteria, accreditation statements, contact information, and event announcements should be verified against official university sources before the website is used as an official information channel.
