📌 Project Overview

The GCWUS Department of Computer Science Website is a modern, responsive, and user-friendly web project designed to present departmental information in a professional and visually appealing way.

Developed for Government College Women University Sialkot, the website provides an organized platform for students, prospective applicants, faculty members, and visitors to explore academic programs, faculty profiles, research areas, computing laboratories, departmental news, and contact information.

The project focuses on clean UI design, responsive layouts, interactive components, and smooth navigation to create an engaging user experience across desktop, tablet, and mobile devices.

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

You will need:

A modern web browser, such as Google Chrome, Microsoft Edge, or Mozilla Firefox.
A code editor, such as Visual Studio Code (optional).
An internet connection to load external stylesheets, fonts, icons, and images.
Installation

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/gcwus-computer-science-website.git


Replace YOUR-USERNAME with your GitHub username and update the repository URL if necessary.

2. Navigate to the project directory

cd gcwus-computer-science-website


3. Open the project

Open the index.html file directly in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension to launch the website locally.

No backend server or database is required to run the current version.

⚙️ Current Limitations

Although the website provides several interactive features, some functionality is currently implemented for demonstration purposes.

Contact Form: Displays a success notification but does not send messages to a backend or email address.
Faculty Directory: Search and filtering operate only on the faculty records included in the HTML.
Academic Programs: Program information is stored in a JavaScript object rather than a database.
News and Events: Content is static and must be updated manually.
Backend Integration: No backend server, database, authentication, or administrative dashboard is currently implemented.
External Dependencies: Tailwind CSS, Font Awesome, Google Fonts, and external images may require an internet connection.
Important: Faculty details, admission requirements, accreditation statements, contact information, and event announcements should be verified against official university sources before the website is used as an official information channel.

🌐 Deployment

Since this project is a static HTML website, it can be deployed using a static hosting platform without requiring a backend server.

Popular deployment options include:

GitHub Pages — Host the website directly from a GitHub repository.
Netlify — Deploy the website with a simple hosting workflow.
Vercel — Deploy and host the static website.
Quick Deployment with GitHub Pages
Upload the project files to a GitHub repository.
Open the repository's Settings.
Navigate to Pages.
Select the appropriate branch, usually main, and the root directory.
Save the configuration and wait for deployment to complete.
Open the published website URL provided by GitHub Pages.

Make sure index.html is located in the selected publishing directory.
