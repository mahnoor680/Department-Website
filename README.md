
# 💻 GCWUS - Computer Science Department

A responsive website for the Department of Computer Science at Government College Women University Sialkot (GCWUS).

## ✨ Features
- 📚 Academic programs and faculty directory
- 🔍 Faculty search and filtering
- 🧪 Research and computer labs sections
- 📰 News and events
- 📩 Contact form with interactive modals
- 📱 Responsive design

## 🛠️ Technologies
- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
